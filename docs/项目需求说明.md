# MindPilot-GPT 项目需求说明

> 一站式「万能视频下载 + 字幕转写 + AI 分析」Web 工具：粘贴链接 → 解析 → 下载 / 字幕 / 总结 / 思维导图 / 高赞评论 / 多轮问答。
> 技术栈：FastAPI + yt-dlp + SQLite 缓存 + Tailwind CDN 原生 JS 单页；门面 + 可插拔包架构（`downloader` / `transcribe` / `ai` / `comments` / `storage`）。
> 本文按优先级梳理**已实现需求**与**后续可扩展需求**，作为迭代路线图依据。

---

## 一、已实现需求（按优先级）

### P0 核心链路（产品立身之本）

| # | 需求 | 说明                                                                                                 | 实现落点 |
|---|------|----------------------------------------------------------------------------------------------------|----------|
| 1 | 视频解析与下载 | 解析元信息（标题/封面/作者/时长/清晰度格式列表）；服务端下载并流式回传，ffmpeg 高清音视频合并                                               | `POST/GET /api/info`、`/api/download`；`downloader` 门面 + registry：抖音专用（短链/跳转/WAF 对抗）优先，其余回退 generic yt-dlp |
| 2 | 字幕转写（字幕优先 → ASR 兜底） | 优先零成本提取平台内嵌字幕；无字幕时抽音频走 ASR 链（硅基 SenseVoice → 通义 Qwen3-ASR → 自定义 OpenAI 兼容），失败自动降级下一家               | `POST /api/transcribe`；`transcribe/subtitles.py` + `asr.py` + `audio.py` |
| 3 | AI 结构化总结 | 字幕 → LLM 生成摘要/要点/章节；支持多家 OpenAI 兼容模型                                                               | `POST /api/summarize`；`ai/summary.py` + `ai/config.py` |
| 4 | 结果页交互骨架 | 单页（Tailwind CDN、无第三方前端库）：解析 → 视频卡片双栏（左列表/右详情）；五 Tab（总结摘要·字幕文本·思维导图·高赞评论·AI 问答）；懒加载 + 会话级缓存 + 客户端去重 | `frontend/app.js` |

### P1 AI 增强与内容扩展

| # | 需求            | 说明 | 实现落点 |
|---|---------------|------|----------|
| 5 | AI 思维导图       | LLM 生成层级结构；前端 Canvas 自绘（缩放/拖拽/折叠），支持导出 PNG | `POST /api/mindmap`；`ai/mindmap.py` |

## 二、后续可扩展需求（按优先级）

### P0 价值明确、成本可控

1. **弹幕抓取**：将 `comments/` 升格为 `social/`（或 `ugc/`）伞包，`comments` 与 `danmaku` 为平级能力；**独立缓存表 / 独立端点 / 独立前端 Tab**（弹幕为视频时间轴数据，schema 与排序维度不同于评论）。抓取与解析**无需 LLM**（XML/protobuf 确定性解析）；因量级大，服务端须按时间密度分桶采样限流后再回传。
2. **AI 评论 / 弹幕洞察（可选 LLM）**：观点聚类、情感时间线、梗总结；复用 `ai/summarize` 范式 + 独立缓存键，点到才调用，主链路保持零成本。
3. **存储升级 Postgres（阶段 1）**：`DATABASE_URL` 切换即迁移，ORM 已抽象、业务代码零改动

### P1 中期增强

4. **平台扩展**：快手 / 小红书 / 公众号 / 喜马拉雅等平台的 downloader 与 comments 适配器（遵循 registry 调度与「小写拼音文件名」命名约定）。
5. **分析报告导出**：总结 + 思维导图 PNG + 高赞评论打包导出 Markdown / PDF。
6. **下载体验升级**：长下载改异步任务队列 + 进度条回传；批量解析与批量导出。
7. **前端增强**：弹幕叠加渲染、评论情感时间线图表、思维导图 Markdown 导出。

### P2 长期演进

8. **多用户与鉴权**：登录 / 会话、按用户的历史与收藏（需引入用户表与会话管理）。
9. **Provider 管理 UI**：ASR / LLM 提供商切换与采样参数（temperature 等）可视化配置（当前仅环境变量）。
10. **分布式与国际化**：Redis 分布式锁解决多进程写冲突（伴随阶段 1）；i18n 与移动端深度优化。

## 四、关键环境变量

| 变量 | 用途 | 默认 |
|------|------|------|
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL_ID` | OpenAI 兼容大模型接入 | 无（未配置时 AI 功能 503 引导） |
| `DASHSCOPE_API_KEY` / `SILICONFLOW_API_KEY` | 通义 / 硅基预设 Key | 无 |
| `ASR_PROVIDER` / `ASR_API_KEY` / `ASR_BASE_URL` / `ASR_MODEL` / `ASR_STYLE` / `ASR_LABEL` / `ASR_LANGUAGE` | 自定义 ASR 覆盖预设链 | 预设链 siliconflow → dashscope |
| `DATABASE_URL` | 存储后端（sqlite / postgres） | SQLite 本地库 |
| `CACHE_ENABLED` | 缓存总开关（灰度） | `true` |
| `TRANSCRIPT_CACHE_DAYS` | 字幕缓存 TTL | 30 天 |
| `COMMENTS_CACHE_HOURS` | 评论缓存 TTL（<=0 永不过期） | 12 小时 |

## 五、架构原则（约束后续迭代）

1. **门面 + 可插拔**：每个能力包对外单一门面函数，平台/Provider 以「契约函数 + 注册表」接入，新增平台不改门面与前端。
2. **LLM 边界**：确定性 IO/计算（抓取、排序、解析）绝不调 LLM；LLM 仅用于「加工」类增强，且懒加载（点到才调）+ 缓存。
3. **缓存优先 + 并发去重**：所有上游结果经 storage 缓存与 single-flight，二次访问秒开。
4. **密钥只来自环境**：任何密钥不进代码、不进 Git。
5. **前端零构建零依赖**：Tailwind CDN + 原生 JS，图表/导图一律 Canvas/CSS 自绘。
