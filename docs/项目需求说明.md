# MindPilot-GPT 项目需求说明

> 一站式「万能视频下载 + 字幕转写 + AI 分析 + 知识沉淀」Web 工具：粘贴链接 → 解析 → 下载 / 播放 / 字幕 / 总结 /
> 思维导图 / 高赞评论 / 多轮问答 / 随手笔记；登录用户自动沉淀处理历史、合集与 QA 会话，并可短链分享分析结果。
> 技术栈：FastAPI + yt-dlp + SQLite 缓存 + Tailwind CDN 原生 JS 单页；门面 + 可插拔包架构
> （`downloader` / `transcribe` / `ai` / `comments` / `auth` / `library` / `notes` / `share` / `seo` / `storage`）。
> 本文按优先级梳理**已实现需求**与**后续可扩展需求**，作为迭代路线图依据。
> 注意：本文为需求视角；**当前版本完整实现见 [项目实现总结.md](./项目实现总结.md)**，文档导航见 [README.md](./README.md)。

## 二、后续可扩展需求（按优先级）

> **落地进展标注（2026-10-18 复核）**：本清单为早期路线图，多项已随迭代落地。
> ✅ = 已实现，🟡 = 部分实现，⬜ = 未实现。已实现项的详细设计见对应方案文档（索引见 [README.md](./README.md)）。

### P0 价值明确、成本可控

1. **弹幕抓取**：将 `comments/` 升格为 `social/`（或 `ugc/`）伞包，`comments` 与 `danmaku` 为平级能力；**独立缓存表 / 独立端点 / 独立前端 Tab**（弹幕为视频时间轴数据，schema 与排序维度不同于评论）。抓取与解析**无需 LLM**（XML/protobuf 确定性解析）；因量级大，服务端须按时间密度分桶采样限流后再回传。⬜
2. **AI 评论 / 弹幕洞察（可选 LLM）**：观点聚类、情感时间线、梗总结；复用 `ai/summarize` 范式 + 独立缓存键，点到才调用，主链路保持零成本。⬜
3. **存储升级 Postgres（阶段 1）**：`DATABASE_URL` 切换即迁移，ORM 已抽象、业务代码零改动。🟡（代码已就绪，待生产切换）

## 五、架构原则（约束后续迭代）

1. **门面 + 可插拔**：每个能力包对外单一门面函数，平台/Provider 以「契约函数 + 注册表」接入，新增平台不改门面与前端。
2. **LLM 边界**：确定性 IO/计算（抓取、排序、解析）绝不调 LLM；LLM 仅用于「加工」类增强，且懒加载（点到才调）+ 缓存。
3. **缓存优先 + 并发去重**：所有上游结果经 storage 缓存与 single-flight，二次访问秒开。
4. **密钥只来自环境**：任何密钥不进代码、不进 Git。
5. **前端零构建零依赖**：Tailwind CDN + 原生 JS，图表/导图一律 Canvas/CSS 自绘。
